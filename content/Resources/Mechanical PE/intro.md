# Mechanical PE Notes

In an effort to better learn the concepts outlined in my studies for the Mechanical Engineering - Thermal Fluids Professional Engineering exam, I am documenting my learnings into a series of pages so that it may be fun to look back at in the future.

This may also be useful to visitors who may stumble across this page where they might make use of what I've logged here.

My thoughts so far:
- The pages will be structured according to domain or concept that I learn.
- On certain concepts I'll provide resources on where to learn more about the topic.
- I will attempt to make a tool of some sort that best explains or shows the concept visually done in one of the following ways. It may be overkill, but I enjoy writing in Rust, Zig and Go and this will keep me actively learning more about the languages. If you're not familiar with these, I will be writing more on them soon:
	- Rust functions compiled to WASM with a UI in html with CSS styling and Vanilla JavaScript for the glue code and UI logic.  
	- Zig program using raylib-zig (bindings for [raylib](https://www.raylib.com/) game engine) compiled into WASM.
- If there is anything I can provide context on from my experience, I will do so.
